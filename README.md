# Cyprus Real Estate - Express Travel

Сайт недвижимости на Кипре от компании Express Travel.

## Возможности

- Каталог недвижимости на Кипре
- Туры для выбора недвижимости
- Поездки на Кипр (комбинированные туры)
- Экскурсии по Европе
- Многоязычность (RU/EN)
- Админ-панель для управления экскурсиями
- Формы заявок с согласием на обработку данных
- Cookie-баннер

## Технологии

- React 18 + TypeScript
- Vite
- Tailwind CSS
- React Router
- i18next
- Lucide React (иконки)

## Разработка

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Деплой

Проект деплоится на сервер через Dokploy API.

## Структура

- `/src/pages` - страницы сайта
- `/src/components` - переиспользуемые компоненты
- `/src/i18n` - локализация
- `/public/images` - изображения
