## 2. Технические и организационные меры

- Обязательная проверка согласия на сервере при создании заявки.
- Сохранение версии политики и серверного времени принятия согласия в записи заявки.
- Пароль администратора не хранится в браузере; сервер выдаёт подписанный токен с ограниченным сроком действия.
- Проверка токена выполняется на каждом административном API-запросе.
- Ограничение частоты запросов для форм и входа; honeypot-поле в формах заявки.
- Файловое хранилище заявок должно располагаться на постоянном томе с контролем доступа.
- Необязательная карта не создаёт iframe и не обращается к OpenStreetMap до согласия.
- Отключение функциональной категории удаляет iframe и прекращает новые запросы к поставщику.
- Регулярное удаление заявок администратором и резервное копирование должны быть организованы оператором.

## 3. Сроки ответа и права субъектов

Запросы направляются через форму `/data-rights`, которая подготавливает письмо на `info@express-travel.com`, или непосредственно на этот адрес. Сайт не хранит отдельную базу DSAR.

Перед раскрытием или удалением данных оператор должен:

1. Проверить личность заявителя соразмерно риску.
2. Найти данные по предоставленным контактным сведениям.
3. Ответить в течение одного месяца; при допустимом продлении уведомить заявителя.
4. Зафиксировать факт исполнения запроса без избыточного копирования персональных данных.

## 4. Открытые решения перед публикацией и эксплуатацией

- [ ] Подтвердить точное юридическое наименование оператора и регистрационные реквизиты. Сейчас на сайте используется бренд Express Travel.
- [ ] Определить, обязателен ли DPO по критериям GDPR; если да, добавить его контакты в политику и реестр.
- [ ] Утвердить срок хранения заявок. При необходимости задать `LEAD_RETENTION_DAYS` в окружении; пустое значение отключает автоматическое удаление по возрасту.
- [ ] Указать фактических хостинг- и инфраструктурных поставщиков, страны обработки, договоры и гарантии передач.
- [ ] Проверить правила OpenStreetMap и применимость требований о международной передаче при загрузке карты.
- [ ] Назначить владельца RoPA и дату регулярного пересмотра.
- [ ] Провести инвентаризацию старых заявок: записи до версии политики 2026-11-24 не содержат доказательства согласия.
- [ ] Включить HTTPS на production-домене до сбора персональных данных через формы. Текущий адрес `http://cyprus-estate.pro` работает только по HTTP.
- [ ] Настроить резервное копирование, ограничение доступа и удаление данных из резервных копий по утверждённому графику.

## 5. Источники фактических сведений

- `server/index.js` — API заявок, админская авторизация, rate limiting, файловое хранилище.
- `src/lib/consent.ts` — версия, категории и доказательство выбора cookie.
- `src/lib/api.ts` — хранение админского токена в `sessionStorage`.
- `src/pages/PropertyPage.tsx` — consent-gate карты OpenStreetMap.
- `src/pages/ContactsPage.tsx` и `src/pages/PropertyPage.tsx` — состав данных форм.
- `src/pages/PrivacyPage.tsx`, `src/pages/CookiePolicyPage.tsx`, `src/pages/DataRightsPage.tsx` — публичные уведомления и канал реализации прав.
